# SolitonLab-HM
Интерактивный комплекс для численного моделирования, качественного анализа и 3D/SDE/FFT визуализации нелинейной волновой динамики, солитонов и хаоса в системе Хироты–Маккари.
# Интерактивный комплекс моделирования нелинейной волновой динамики системы Хироты–Маккари

Данный программный комплекс предназначен для численного анализа, качественного исследования и визуализации волновых решений связанных нелинейных уравнений в частных производных (УЧП) системы Хироты–Маккари. 

Программа объединяет методы качественной теории дифференциальных уравнений, нелинейной динамики, спектральных методов решения УЧП и теории детерминированного хаоса. Она разработана как вспомогательный инструмент для научно-исследовательских работ, диссертаций и презентаций по нелинейной физике.

---

## 1. Теоретическая база модели

Исходная система уравнений Хироты–Маккари представляет собой связанную систему нелинейных уравнений в частных производных размерности $(2+1)\text{D}$ для комплексного волнового поля $\phi(x,y,t)$ и вещественного потенциала $\psi(x,y,t)$:
$$i\phi_t + \phi_{xy} + i\phi_{xxx} + \phi\psi - i|\phi|^2 \phi_x = 0$$
$$3\psi_x + (|\phi|^2)_y = 0$$

Для отыскания уединенных волновых решений применяется автомодельная подстановка бегущей волны (косого плоского фронта):
$$\xi = a_1 x + a_2 y + a_3 t, \quad \theta = b_1 x + b_2 y + b_3 t$$
$$\phi(x,y,t) = \Phi(\xi)e^{i\theta}, \quad \psi(x,y,t) = \Psi(\xi)$$

После математического усреднения (в дробно-стохастическом случае) система редуцируется к нелинейному обыкновенному дифференциальному уравнению (ОДУ) второго порядка типа кубического уравнения Дуффинга:
$$\Phi''(\xi) - c_1 \Phi^3(\xi) - c_2 \Phi(\xi) = 0$$

Для качественного анализа автономного ОДУ оно переписывается в виде динамической системы первого порядка на фазовой плоскости $(\Phi, y)$:
$$\begin{cases} \frac{d\Phi}{d\xi} = y \\ \frac{dy}{d\xi} = c_1 \Phi^3 + c_2 \Phi \end{cases}$$

Система является консервативной (гамильтоновой) с сохраняющейся во времени энергией (первым интегралом Гамильтона):
$$H(\Phi, y) = \frac{1}{2} y^2 - \frac{c_1}{4} \Phi^4 - \frac{c_2}{2} \Phi^2 = \text{const}$$

## 2. Описание модулей лабораторного комплекса

### 1. Демонстрация 4 качественных структур фазовых портретов
Визуализирует фазовое пространство автономной системы для четырех фундаментальных знаковых комбинаций параметров $c_1$ и $c_2$, определяющих поведение системы:
* **Случай 1 ($c_1 > 0, c_2 > 0$):** Положение равновесия $(0,0)$ — седло. Замкнутые траектории отсутствуют, волновые решения уходят в бесконечность.
* **Случай 2 ($c_1 < 0, c_2 < 0$):** Положение равновесия $(0,0)$ — центр. Система совершает периодические колебания вокруг нуля (периодические кноидальные волны Якоби).
* **Случай 3 ($c_1 > 0, c_2 < 0$):** Положение равновесия $(0,0)$ — центр. В точках $\pm\sqrt{-c_2/c_1}$ находятся два седла, соединенные гетероклиническими траекториями (тёмный солитон / кинк).
* **Случай 4 ($c_1 < 0, c_2 > 0$):** Точка $(0,0)$ — седло. В точках $\pm\sqrt{-c_2/c_1}$ находятся два центра. Седло замыкается гомоклинической петлей сепаратрисы типа «восьмерка» (светлый солитон).

### 2. Построение фазового портрета для произвольных параметров ($c_1, c_2$)
Находит положения равновесия $(\Phi^*, 0)$ как корни алгебраического уравнения $c_1 \Phi^3 + c_2 \Phi = 0$. Программа рассчитывает собственные значения матрицы Якоби:
$$\lambda^2 = 3c_1 (\Phi^*)^2 + c_2$$
Если $\lambda^2 > 0$ — точка классифицируется как седло, если $\lambda^2 < 0$ — как устойчивый центр. Модуль строит векторное поле, нуль-клинали ($\frac{d\Phi}{d\xi}=0 \implies y=0$ и $\frac{dy}{d\xi}=0 \implies c_1\Phi^3+c_2\Phi=0$), особые точки и интегрирует сепаратрисы, смещаясь из седла на малую величину $\pm\epsilon$ вдоль собственных векторов.

### 3. Сравнение численного и точного аналитического решений
Оценивает погрешность численной интеграции ОДУ по сравнению с точными аналитическими функциями:
* **Эллиптический косинус Якоби:** $\Phi(\xi) = A \text{cn}(\omega \xi, m)$, где $\omega = \sqrt{\frac{c_2}{2m-1}}$, $A = \sqrt{\frac{2m}{1-2m}\frac{c_2}{c_1}}$ ($m \in (0, 0.5)$).
* **Тёмный солитон:** $\Phi(\xi) = \sqrt{-c_2/c_1}\tanh\left(\sqrt{-c_2/2}\xi\right)$.
* **Светлый солитон:** $\Phi(\xi) = \sqrt{-2c_2/c_1}\text{sech}(\sqrt{c_2}\xi)$.

Численная схема `DOP853` интегрирует ОДУ в обе стороны (вперед и назад) из геометрического центра $\xi=0.0$, что исключает вычислительную неустойчивость в окрестностях седел. Программа интерполирует результат и строит логарифмический график абсолютной погрешности.

### 4. Анимация эволюции портрета при изменении параметров
Использует модуль `FuncAnimation` для динамического отображения бифуркационных перестроек фазового пространства при медленном непрерывном дрейфе параметров $c_1$ или $c_2$. Интегрирование траекторий оптимизировано методом `RK45` с автоматическим отсечением вычислений при уходе за границы экрана во избежание сбоев переполнения.

### 5. Моделирование темного солитона с мультипликативным шумом
Решает стохастическое уравнение Стратоновича (SDE), описывающее динамику темного солитона во флуктуирующей среде:
$$d\Phi = y d\xi, \quad dy = (c_1\Phi^3 + c_2\Phi)d\xi + \epsilon\Phi \circ dW(\xi)$$

Расчет ведется методом Эйлера-Маруямы с шагом $\Delta\xi = 0.004$ по ансамблю из $100$ независимых реализаций винеровского процесса $dW$. Программа находит математическое ожидание профиля $\langle\Phi\rangle$ и дисперсионный коридор $\pm 1 \sigma$ (стандартное отклонение), иллюстрируя физику размытия солитонного фронта шумом.

### 6. Анализ периодического воздействия и сечение Пуанкаре
Моделирует неавтономную систему с внешней вынуждающей силой амплитуды $f_0$ и частоты $\omega$:
$$\frac{d^2\Phi}{d\xi^2} - c_1 \Phi^3 - c_2 \Phi = f_0 \cos(\omega \xi)$$

Строит сечение Пуанкаре (Poincaré Map) — фазовые координаты фиксируются строго в фазе внешней силы через промежутки времени $T = 2\pi/\omega$. Позволяет визуализировать фазовые перестройки: замкнутые инвариантные кривые (квазипериодические режимы) и хаотические аттракторы (детерминированный хаос).

### 7. Построить 3D пространственный солитон $|\phi(x,y,t)|^2$
Осуществляет обратный переход от автомодельного одномерного ОДУ к исходным плоским физическим координатам УЧП в пространстве $(x,y)$ в фиксированный момент времени $t$:
$$| \phi(x,y,t) |^2 = \Phi^2(a_1 x + a_2 y + a_3 t)$$

Строит наклонную трехмерную волновую поверхность (солитонный хребет) на плоскости $xy$.

### 8. Построить фрактальную бифуркационную диаграмму хаоса
Использует численный метод продолжения по параметру. Программа выполняет сканирование (свип) амплитуды внешней силы $f_0$ на интервале $[0, 2.8]$. Для каждого шага отбрасывается переходный процесс (первые 120 периодов колебаний) и наносятся установившиеся точки сечения Пуанкаре. Диаграмма наглядно демонстрирует сценарий перехода к хаосу через каскад удвоения периода (сценарий Фейгенбаума) и фрактальную структуру зон хаотической динамики.

### 9. Построить влияние порядка дробной производной $\alpha$
Численно оценивает влияние дробного интегро-дифференциального порядка $\alpha \in (0, 1]$ на профиль солитона. Согласно дробно-дифференциальному исчислению, эффективный коэффициент линейной возвращающей силы масштабируется как:
$$c_2^{(\alpha)} = c_2 |p|^{2(\alpha-1)}$$
где $p$ — волновое число. Программа строит солитонные профили для различных значений $\alpha$, иллюстрируя уширение импульса и падение его амплитуды (эффект дробной пространственной дисперсии) при уменьшении $\alpha$.

### 10. Проверить инвариант энергии (Гамильтониан)
Рассчитывает полную энергию (первый интеграл Гамильтона) вдоль замкнутой фазовой траектории детерминированной системы:
$$H(\Phi, y) = \frac{1}{2} y^2 - \frac{c_1}{4} \Phi^4 - \frac{c_2}{2} \Phi^2 = \text{const}$$

Оценивает дрейф энергии $|H(\xi) - H(0)|$ на длительном интервале времени. Позволяет оценить высокую консервативную точность алгоритма `DOP853` (погрешность удержания инварианта составляет порядка $10^{-13} - 10^{-14}$).

### 11. Спектральный анализ Фурье (БПФ/FFT) и диагностика хаоса
Выполняет спектральное разложение устоявшегося временного ряда $\Phi(\xi)$ с использованием Быстрого Преобразования Фурье (FFT). Строит спектр плотности мощности. Служит математическим доказательством перехода к хаосу: периодические колебания дают узкие дискретные пики на частоте возбуждения и ее гармониках, а хаотический режим характеризуется сплошным широкополосным спектром.

### 12. Построить эволюцию 2-солитонного связанного состояния
Воспроизводит точное аналитическое двухсолитонное решение уравнения НУШ — дышащий солитон (breather) Сацумы–Ядзимы, полученное классическим методом Хироты. Строит пространственно-временную эволюцию $|u(x,t)|^2$ в виде 3D-поверхности и 2D-проекции, иллюстрируя периодические биения двух связанных уединенных волн.

### 13. Расчет показателя Ляпунова (метод Бенеттина) для хаоса
Для строгого доказательства хаотичности колебаний рассчитывает старший показатель Ляпунова ($\lambda$) по алгоритму Бенеттина. Программа параллельно интегрирует две близкие фазовые траектории (номинальную $Y_1$ и возмущенную $Y_2$ на расстояние $d_0 = 10^{-8}$):
$$\lambda = \lim_{M \to \infty} \frac{1}{M \Delta t} \sum_{k=1}^M \ln\left(\frac{d_k}{d_0}\right)$$
На каждом шаге $\Delta t$ измеряется новое расстояние $d_k$, накапливается показатель расходимости, и возмущенная траектория возвращается на исходную сферу радиуса $d_0$ вдоль направления расходимости. Знак $\lambda$ однозначно характеризует систему: $\lambda > 0$ — хаос, $\lambda \le 0$ — регулярное движение.

### 14. Моделирование столкновения солитонов (УЧП Шрёдингера, SSFM)
Решает исходное нестационарное уравнение в частных производных (УЧП) методом расщепления по физическим процессам на шагах Фурье (Split-Step Fourier Method, SSFM):
$$\psi(x, t+\Delta t) = \text{IDFT}\left( \text{DFT}(\psi) e^{-i \frac{k^2}{2}\Delta t} \right) \cdot e^{i |\psi|^2 \Delta t}$$

В качестве начального условия задается пара движущихся навстречу друг другу светлых солитонов различной амплитуды. Моделирование иллюстрирует упругое соударение, фазовый сдвиг и последующий разлет солитонов без изменения их формы.

### 15. Анимация столкновения солитонов в реальном времени (2D профиль)
Прекомпилирует временные слои численной схемы метода SSFM и строит плавную двумерную анимацию эволюции профиля интенсивности $|\psi(x,t)|^2$ во времени, демонстрируя динамический процесс упругого удара и прохождения.

### 16. 3D-анимация столкновения волн на плоскости xy (УЧП)
Строит динамическую трехмерную анимацию упругого лобового столкновения и разлета двух пространственно локализованных солитонов (дромионов) на двумерной плоскости $xy$ во времени:
$$|\phi(x,y,t)|^2 = \left( \frac{A_1}{\cosh(x - v t)\cosh(y)} + \frac{A_2}{\cosh(x + v t)\cosh(y)} \right)^2$$

Визуализирует процесс сближения, слияния в центральный пик нелинейного взаимодействия и последующий разлет волновых пакетов с медленным вращением 3D-камеры.

### 17. Рассеяние и захват солитона на потенциальном барьере/яме (УЧП)
Моделирует распространение уединенного волнового пакета во внешних пространственных потенциалах $V(x)$ методом SSFM:
$$i \psi_t + \frac{1}{2} \psi_{xx} + |\psi|^2 \psi - V(x)\psi = 0$$
* **Потенциальный барьер ($V(x) > 0$):** Моделирует упругое отражение солитона (солитон замедляется у барьера и отскакивает назад).
* **Потенциальная яма ($V(x) < 0$):** Моделирует притяжение и ускорение солитона при пролете ямы.
* **Оптическая решетка ($V(x) \sim \sin^2(qx)$):** Иллюстрирует пространственную локализацию и захват солитона в периодических ямах решетки (оптический пинцет).

### 18. 3D-анимация пульсаций дышащего солитона (Breather) на плоскости
Осуществляет непрерывную 3D-анимацию на плоскости $xy$ периодических пульсаций (дыхания) пространственно локализованного во времени волнового пакета (модифицированного решения Сацумы-Ядзимы):
$$|u(x,y,t)|^2 = \left| \frac{4 e^{i t} (\cosh(3x) + 3 e^{8it}\cosh(x))}{\cosh(4x) + 4\cosh(2x) + 3\cos(8t) + 12} \right|^2 \cdot \text{sech}^2(y)$$

Наглядно демонстрирует процесс периодического сжатия в единый пик экстремальной амплитуды и последующий распад на два симметричных пакета.
